# 食品過期管理

🔗 線上使用  
https://michael791002.github.io/food-expiry-manager/

一個用來管理食品保存期限與到期提醒的簡易工具，適合個人、家庭、公司冰箱或其他多人共用情境。

## 目前功能

- 帳號註冊與登入
- 記住上一次登入的 Email
- 忘記密碼 / Email 驗證碼重設
- 可建立與加入多個群組
- 群組邀請碼
- Owner / Member / Viewer 權限
- 食品新增、修改、刪除與數量調整
- 食品到期日曆
- 顯示剩餘天數與過期狀態
- OCR 掃描包裝日期
- OCR 失敗時可手動輸入日期
- 延遲批次同步，減少頻繁寫入
- Email 到期提醒
- 每位使用者可自行設定提醒時間
- 不同群組可分別設定是否提醒
- 不同群組可設定不同提前提醒天數
- 單一食品可使用群組預設、自訂提醒天數或關閉提醒

## 群組權限

### Owner
- 管理群組名稱
- 產生邀請碼
- 管理成員
- 調整 Member / Viewer 權限
- 新增、修改、刪除食品
- 刪除群組

### Member
- 查看食品
- 新增、修改、刪除食品

### Viewer
- 僅查看食品資料
- 無法新增、修改或刪除

## 到期提醒

每位使用者可以自行決定：

- 是否啟用 Email 提醒
- 每天哪一個整點接收提醒
- 哪些群組需要提醒
- 每個群組預設提前幾天提醒
- 單一食品是否使用群組預設、改成自訂天數，或完全不提醒

同一天有多個群組或多項食品需要提醒時，會整理成一封摘要 Email。

## OCR 日期辨識

新增食品時可以：

1. 拍照或選擇圖片
2. 框選日期區域
3. 辨識包裝上的日期
4. 選擇辨識結果
5. 自動填入到期日

如果辨識失敗，仍可以直接手動輸入日期。
